# Security Policy

QA Agent may read product documents, bug reports, API documents, database notes, logs, and test reports. Treat all of these as potentially sensitive.

## Reporting Security Issues

Do not disclose sensitive project data in public issues. Report security issues through the repository's private vulnerability reporting channel when available, or contact the maintainers listed by the project owner.

## Data Handling Rules

- Do not include secrets, tokens, customer data, or private logs in examples.
- Mask credentials and personal information in test reports.
- Keep issue submission provider-specific and configurable.
- Do not upload local artifacts unless the user explicitly confirms.
