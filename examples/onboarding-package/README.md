# Example QA Onboarding Package

Use this directory as a template for a real project's QA onboarding input.

```text
qa-onboarding-input/
  00-project-structure.md
  01-product-overview.md
  02-product-screens/
  03-product-docs/
  04-api-docs/
  05-database-docs/
  06-test-cases/
  07-bug-history/
  08-test-reports/
  09-automation/
```

Run:

```bash
ae qa start examples/onboarding-package
```

The example intentionally contains only placeholders. Real projects should replace them with sanitized product materials.
