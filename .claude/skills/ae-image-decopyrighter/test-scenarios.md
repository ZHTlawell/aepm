# ae-image-decopyrighter 测试场景

## 场景 1：单张图片去版权
- **用户说**："帮我把这张图片去版权"
- **预期行为**：agent 读取原图理解内容，调用脚本生成替代图片，展示原图 vs 新图对比
- **验证标准**：输出图片语义一致但视觉有差异，无品牌/logo

## 场景 2：批量目录处理
- **用户说**："把 assets/images/ 目录下的图片都去版权"
- **预期行为**：遍历目录中所有图片文件，逐张处理
- **验证标准**：所有图片都被处理，输出数量与输入一致

## 场景 3：GEMINI_API_KEY 未配置
- **用户说**："去版权"（无 GEMINI_API_KEY）
- **预期行为**：检测到 key 缺失，引导用户获取并配置
- **验证标准**：给出获取 key 的步骤和配置命令

## 场景 4：指定风格重绘
- **用户说**："把这张图片去版权，用插画风格"
- **预期行为**：传递 --style 参数，生成插画风格图片
- **验证标准**：输出图片为插画风格

## 场景 5：切换到备选后端
- **用户说**："Gemini 太慢了，用 DALL-E 试试"
- **预期行为**：检查 OPENAI_API_KEY，切换 --backend dalle 执行
- **验证标准**：使用 DALL-E 后端生成图片
