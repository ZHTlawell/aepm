# 缺陷报告标准

## 必填字段

- 标题：`[BUG] 产品/模块 - 问题摘要`
- 环境：版本、设备、系统、账号角色、后端环境
- 前置条件
- 复现步骤
- 实际结果
- 期望结果
- 严重程度：Blocker / Critical / Major / Minor
- 影响范围
- 附件：截图、录屏、日志、接口响应
- 验证标准

## 提交规则

1. 提交前必须查重。
2. 提交前必须展示完整 issue 内容让用户确认。
3. 多个独立问题拆成多个 issue。
4. 验证标准不能为空。
5. 优先通过 `.qa-agent.yml` 配置的 issue provider 提交；未配置时输出可复制的 issue 正文。
